# Página Pessoal — HTML e CSS

Este repositório contém minha página pessoal, desenvolvida para um trabalho de **Desenvolvimento de Sistemas**. O objetivo foi aproveitar uma página feita anteriormente em HTML e aplicar os conceitos de CSS estudados durante as aulas.

## Sobre a página

O site apresenta algumas informações sobre mim, curiosidades, lugares que já conheci e destinos que gostaria de conhecer.

A identidade visual utiliza fundos escuros, tons dourados e verdes, com uma temática de biblioteca e fantasia.

## Tecnologias e conteúdos

- **HTML5:** organização do conteúdo e navegação entre seções.
- **CSS3:** cores, fontes, bordas, espaçamentos e imagens de fundo.
- **Flexbox:** alinhamento do menu, apresentação pessoal e cartões.
- **CSS Grid:** organização das curiosidades e dos lugares.
- **Pseudoclasses:** efeitos visuais em links, botões e cartões.
- **Google Fonts:** fontes Cinzel e Work Sans.

O projeto foi desenvolvido sem JavaScript ou frameworks CSS.

## Como visualizar

Acesse a [página publicada no GitHub Pages](https://miguel4144.github.io/PaginaPessoalCSS/) **após a publicação ser configurada**.

Também é possível abrir `index.html` no navegador e acessar a página pessoal pelo link inicial.
